# A new kind of computer workspace

CAPSULA starts with a simple idea: give intelligence a place to work.

A workspace is not just a folder. It is a durable context for a person or team,
with projects, goals, agents, access rights and artifacts. A computer is an
execution surface. A capsule is a disposable computer for a bounded task.
The execution ends; the useful work remains.

## Five principles

1. **People own the objective.** Agents may interpret and delegate it, but may
   never silently extend the authority they receive.
2. **Every agent has a place.** Persistent agent computers and temporary
   execution capsules serve different needs and must not be conflated.
3. **Execution is observable.** Show plans, status, boundaries, results,
   denials and receipts—not fabricated completion.
4. **Infrastructure should disappear behind utility.** Vultr Cloud Compute
   provides scalable computers, networking and capacity. Users work with
   missions and outcomes rather than VM admin consoles.
5. **Grow by verified capabilities.** A repeatable test, strong isolation
   and useful artifacts are more valuable than a long feature list.

## The direction

CAPSULA is intended to become an operating layer for distributed human and
agent work: private projects, team workspaces, autonomous specialist agents,
reusable skills, browser and code environments, secure external API actions,
hardware-backed identity and more capable multi-host execution.

Not all elements are live. Current source, deployed service status and
provider claims must remain separately verifiable.
